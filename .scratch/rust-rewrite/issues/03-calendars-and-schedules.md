# 03: 交易日历、观察日程与生成工具

**What to build:** 用户可以在 Rust 和 Python 中使用现有交易日历、生成观察日程并查询交易日；维护者可以生成供 Rust 核心使用的上交所日历数据。

**Blocked by:** 01: 欧式解析定价贯通。

**Status:** completed

- [x] 迁移全日历、工作日日历、上交所日历及固定间隔、月度观察日程，保留年化基数、调整方向、区间端点和支持日期范围。
- [x] 自定义开闭市覆盖保留排序与重复日期、冲突日期、拥有值和基数规则；Rust 保留自定义交易日判断及其确定性和并发约束，不新增 Python 回调。
- [x] 日程与日历的非法输入、无可调整日期、非正年化基数和日期边界通过公开 API 验证，错误类别及验证时机一致。
- [x] 日历生成工具输出可由 Rust 消费的数据，原有工具测试适配新格式；核对生成数据与日历查询一致，运行核心无需该 Python 生成工具。
- [x] 生成与维护流程、数据来源和许可说明保持有效；在两种 API 测试等价的日历、调整和观察日程场景。
- [x] 通过 Rust 与 Python 公共 API 验收本票能力，等价领域场景使用同一核心语义与默认值；适配层只处理协议、转换、异常和所有权，导出、类型声明与用法文档同步。
- [x] 迁移本票适用的现有契约与数值回归，覆盖合法和非法输入、验证时机、稳定错误类别及失败状态；Python 表示错误保留原生异常并拒绝意外有损转换。
- [x] 本票与已完成切片在隔离候选环境中通过测试，旧实现继续用于迁移对照；不提前删除旧实现，不新增性能回归门槛或性能报告要求。


## 实现与验证（2026-10-27）

- Rust 核心新增全日历、工作日与上交所日历，保留 365 / 252 / 243 年化基数、双向调整、半开区间计数与交易年分数；自定义覆盖拥有输入并规范化排序和重复日期，冲突与非正基数在构造时返回稳定领域错误。Rust 自定义谓词要求 `Send + Sync + 'static`，确定性与并发约束写入公共文档；Python 不新增回调。
- 固定间隔和月度观察日程保留起点排除、终点上界、following 调整、重复日期合并、月底截断及大间隔/月份偏移边界；公开构造验证生命期、排序、边界与交易日状态。Python 提供只读日期副本、整数/负数索引和保有 owner 的独立迭代器，导出与类型声明同步。
- 生成工具输出 Rust 静态数据，实时上游 `--check` 通过；新表与保留的 C++ 表逐项相同，两套隔离公共 API 逐日核对 1991–2099 年查询。历史数据来源、Apache-2.0 归属与完整许可随核心 crate、候选 wheel 和 sdist 分发；文档说明预测限制与维护流程。
- Windows 上 Rust 1.99.1 通过 19 个核心公共 API 测试及 2 个 rustdoc 示例；CPython 3.15.1 候选版通过全部 38 个测试。共享日历套件在候选与旧版分别通过 16 个测试，另保留欧式 8 个和市场 13 个旧版共享测试通过；旧版完整套件通过 488 个测试，5 个既有条件测试跳过。
- rustfmt、Clippy（拒绝警告）、Ruff 与 Python 类型检查通过；核心在无效 Python 探测路径下通过测试、文档、打包与工作区外消费。最终候选 sdist 可在隔离目录重建 wheel 并安装验证，所有 Rust/Python 文档示例通过执行检查。
- Standards / Spec 独立并行 review 均无实质发现；旧版对照发现并修复整数边界过宽问题，适配层与旧版一致要求 `numbers.Integral`，拒绝未注册的 `__index__` 对象。此次未验证 Linux、其他 CPython 版本及最低 Rust 1.85；未切换正式交付、未发布包，未新增性能门槛。
