# 03: 交易日历、观察日程与生成工具

**What to build:** 用户可以在 Rust 和 Python 中使用现有交易日历、生成观察日程并查询交易日；维护者可以生成供 Rust 核心使用的上交所日历数据。

**Blocked by:** 01: 欧式解析定价贯通。

**Status:** ready-for-agent

- [ ] 迁移全日历、工作日日历、上交所日历及固定间隔、月度观察日程，保留年化基数、调整方向、区间端点和支持日期范围。
- [ ] 自定义开闭市覆盖保留排序与重复日期、冲突日期、拥有值和基数规则；Rust 保留自定义交易日判断及其确定性和并发约束，不新增 Python 回调。
- [ ] 日程与日历的非法输入、无可调整日期、非正年化基数和日期边界通过公开 API 验证，错误类别及验证时机一致。
- [ ] 日历生成工具输出可由 Rust 消费的数据，原有工具测试适配新格式；核对生成数据与日历查询一致，运行核心无需该 Python 生成工具。
- [ ] 生成与维护流程、数据来源和许可说明保持有效；在两种 API 测试等价的日历、调整和观察日程场景。
- [ ] 通过 Rust 与 Python 公共 API 验收本票能力，等价领域场景使用同一核心语义与默认值；适配层只处理协议、转换、异常和所有权，导出、类型声明与用法文档同步。
- [ ] 迁移本票适用的现有契约与数值回归，覆盖合法和非法输入、验证时机、稳定错误类别及失败状态；Python 表示错误保留原生异常并拒绝意外有损转换。
- [ ] 本票与已完成切片在隔离候选环境中通过测试，旧实现继续用于迁移对照；不提前删除旧实现，不新增性能回归门槛或性能报告要求。
