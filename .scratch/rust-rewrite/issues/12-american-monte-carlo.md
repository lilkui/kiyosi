# 12: 美式蒙特卡洛

**What to build:** 用户可以用现有美式回归蒙特卡洛方法定价，并使用受支持的采样、Greeks 和隐含波动率能力。

**Blocked by:** 06: 美式近似定价；11: 欧式 Sobol 与对偶变量。

**Status:** ready-for-agent

- [ ] 沿用现有回归、行权策略、时间步网格与支持范围，保留美式最少步数等产品特定验证。
- [ ] 接入既有伪随机、Sobol 与对偶组合，保留路径数、seed、线程配置及适用统计结果。
- [ ] 迁移美式共享样本 Greeks、产品特定默认差分设置及反求语义，求解容差不被表述为采样误差保证。
- [ ] 以现有美式 MC 回归、独立参考、统计与收敛检查验证，覆盖到期、稀少路径和回归边界。
- [ ] 通过 Rust 与 Python 公共 API 验收本票能力，等价领域场景使用同一核心语义与默认值；适配层只处理协议、转换、异常和所有权，导出、类型声明与用法文档同步。
- [ ] 迁移本票适用的现有契约与数值回归，覆盖合法和非法输入、验证时机、稳定错误类别及失败状态；Python 表示错误保留原生异常并拒绝意外有损转换。
- [ ] 本票与已完成切片在隔离候选环境中通过测试，旧实现继续用于迁移对照；不提前删除旧实现，不新增性能回归门槛或性能报告要求。
