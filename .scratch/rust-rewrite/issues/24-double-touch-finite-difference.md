# 24: 现金双边触碰有限差分

**What to build:** 用户可以定价现金双边触碰和不触碰产品，并正确处理历史触碰、结算时机和支付状态。

**Blocked by:** 17: 二元障碍与单边触碰解析；23: 双障碍有限差分。

**Status:** ready-for-agent

- [ ] 迁移双边触碰产品及现有现金支付和 FD 支持范围，复用双障碍边界与二元结算语义。
- [ ] 触碰定义、共同观察日程、严格既往历史、未知状态和已支付状态保持现有契约。
- [ ] 交付价格及现有分析操作，验证触碰即付与到期支付的允许组合、不可识别状态和非法配置。
- [ ] 迁移双边触碰与结算公开 API 测试，以既有支付关系和收敛检查验证，不新增解析或蒙特卡洛引擎。
- [ ] 通过 Rust 与 Python 公共 API 验收本票能力，等价领域场景使用同一核心语义与默认值；适配层只处理协议、转换、异常和所有权，导出、类型声明与用法文档同步。
- [ ] 迁移本票适用的现有契约与数值回归，覆盖合法和非法输入、验证时机、稳定错误类别及失败状态；Python 表示错误保留原生异常并拒绝意外有损转换。
- [ ] 本票与已完成切片在隔离候选环境中通过测试，旧实现继续用于迁移对照；不提前删除旧实现，不新增性能回归门槛或性能报告要求。
