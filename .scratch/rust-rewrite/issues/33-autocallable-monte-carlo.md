# 33: 雪球与凤凰蒙特卡洛

**What to build:** 用户可以对现有雪球系列和凤凰进行交易日 CPU 模拟，并获得统计、共享路径分析和反求结果。

**Blocked by:** 11: 欧式 Sobol 与对偶变量；31: 结构化产品隐含票息。

**Status:** completed

- [x] 完整覆盖现有结构化变体、交易日步进、观察事件、历史和支付状态，保持早期敲出不会移位后续路径随机抽样的语义。
- [x] 接入既有伪随机、Sobol、对偶与线程设置，保留维度限制、路径计数、seed、标准误差和置信区间规则。
- [x] 交付共享路径 Greeks、隐含波动率及票息求解，未指定 seed 时单次求解共享 seed，票息端点按原语义共享路径。
- [x] 明确求解容差约束所采样价格曲线而非统计误差，迁移固定现金流与无参数暴露的拒绝场景。
- [x] 以现有结构化 MC 回归、支付组合、积分或 FD 参考及线程一致性验证，不添加运行时间门槛。
- [x] 通过 Rust 与 Python 公共 API 验收本票能力，等价领域场景使用同一核心语义与默认值；适配层只处理协议、转换、异常和所有权，导出、类型声明与用法文档同步。
- [x] 迁移本票适用的现有契约与数值回归，覆盖合法和非法输入、验证时机、稳定错误类别及失败状态；Python 表示错误保留原生异常并拒绝意外有损转换。
- [x] 本票与已完成切片在隔离候选环境中通过测试，旧实现继续用于迁移对照；不提前删除旧实现，不新增性能回归门槛或性能报告要求。

## Comments

### 完成核验（2026-10-28）

- 新增 Rust/Python `MonteCarloAutocallableEngine`，覆盖基础、二元、三元雪球、全部八种展开预设与凤凰，复用核心历史、当前事件、支付、障碍边界和固定现金流验证；交易日与事件日之间使用 Actual/365 Fixed 精确对数正态转移。
- 复用 CPU 伪随机、Sobol、对偶、路径计数、seed、线程上限与统计规则；先生成完整路径随机向量，早期敲出不会移位后续路径。无需每日敲入监测时保留观察日与到期日路径，Sobol 维度限制按剩余模拟日期执行。
- 全部十项数值 Greeks、隐含波动率与两类票息求解复用核心接口；未配置 seed 时每次分析或求解固定一个请求内 seed。票息端点保持原有共享随机路径与敲入暴露变化时的独立事件网格语义，容差约束采样价格曲线而非统计误差。
