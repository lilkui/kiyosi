# 21: 单障碍有限差分

**What to build:** 用户可以对现有单障碍支持组合使用 FD 定价和分析，并正确处理观察事件与返还。

**Blocked by:** 09: 香草与数字期权有限差分；16: 单障碍解析定价与事件历史。

**Status:** ready-for-agent

- [ ] 复用已有 FD 方案和网格语义，迁移单障碍事件、连续与日程观察、触碰历史及返还的既有支持范围。
- [ ] 保留观察时点、估值边界和到期处理，不因网格对齐改变原合同日程或历史解释。
- [ ] 交付现有 Greeks、混合敏感度和隐含波动率能力，保留各项差分设置及不可识别状态的领域错误。
- [ ] 迁移障碍 FD 事件、网格、Rannacher、插值和精度回归，使用独立对照与收敛检查验证。
- [ ] 通过 Rust 与 Python 公共 API 验收本票能力，等价领域场景使用同一核心语义与默认值；适配层只处理协议、转换、异常和所有权，导出、类型声明与用法文档同步。
- [ ] 迁移本票适用的现有契约与数值回归，覆盖合法和非法输入、验证时机、稳定错误类别及失败状态；Python 表示错误保留原生异常并拒绝意外有损转换。
- [ ] 本票与已完成切片在隔离候选环境中通过测试，旧实现继续用于迁移对照；不提前删除旧实现，不新增性能回归门槛或性能报告要求。
