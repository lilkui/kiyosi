# 29: 凤凰与数值积分

**What to build:** 用户可以构造凤凰票息与观察条款并使用积分定价，保留现有事件和历史记录行为。

**Blocked by:** 28: 基础雪球与数值积分。

**Status:** ready-for-agent

- [ ] 复用共用结构化领域语义，完整迁移凤凰条款、票息条件、观察事件和支付规则，不引入新产品特性。
- [ ] 历史状态、日期、观察记录和替换由核心验证；未知历史、无事件和已固定现金流保持现有区别。
- [ ] 交付凤凰积分价格、Greeks、敏感度和隐含波动率支持，保留相关默认值及失败类别。
- [ ] 迁移凤凰 API 与积分回归，以现有支付组合和收敛参考验证，基础雪球场景继续通过。
- [ ] 通过 Rust 与 Python 公共 API 验收本票能力，等价领域场景使用同一核心语义与默认值；适配层只处理协议、转换、异常和所有权，导出、类型声明与用法文档同步。
- [ ] 迁移本票适用的现有契约与数值回归，覆盖合法和非法输入、验证时机、稳定错误类别及失败状态；Python 表示错误保留原生异常并拒绝意外有损转换。
- [ ] 本票与已完成切片在隔离候选环境中通过测试，旧实现继续用于迁移对照；不提前删除旧实现，不新增性能回归门槛或性能报告要求。
