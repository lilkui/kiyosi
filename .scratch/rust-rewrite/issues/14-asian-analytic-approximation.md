# 14: 亚式解析与算术平均近似

**What to build:** 用户可以定价几何平均亚式期权或使用现有算术平均近似，并请求已有的分析操作。

**Blocked by:** 04: Greeks、数值敏感度与隐含波动率。

**Status:** ready-for-agent

- [ ] 迁移几何与算术平均产品、平均窗口、历史平均和固定观察相关条款，保持构造与替换的领域验证。
- [ ] 交付几何平均解析与现有算术平均近似及其适用范围，保留前向起始、单次固定和到期边界。
- [ ] 保留各引擎现有 Greeks、数值敏感度、隐含波动率能力及缺失历史或不可识别状态的错误。
- [ ] 迁移亚式解析回归与独立参考；算术平均对照比较同一既有近似，不将其标为真实算术平均价值的精确解。
- [ ] 通过 Rust 与 Python 公共 API 验收本票能力，等价领域场景使用同一核心语义与默认值；适配层只处理协议、转换、异常和所有权，导出、类型声明与用法文档同步。
- [ ] 迁移本票适用的现有契约与数值回归，覆盖合法和非法输入、验证时机、稳定错误类别及失败状态；Python 表示错误保留原生异常并拒绝意外有损转换。
- [ ] 本票与已完成切片在隔离候选环境中通过测试，旧实现继续用于迁移对照；不提前删除旧实现，不新增性能回归门槛或性能报告要求。
