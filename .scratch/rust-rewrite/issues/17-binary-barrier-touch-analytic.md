# 17: 二元障碍与单边触碰解析

**What to build:** 用户可以定价现有二元障碍及单边触碰、不触碰产品，并按既有约定处理现金或资产支付。

**Blocked by:** 16: 单障碍解析定价与事件历史。

**Status:** completed

- [x] 迁移二元障碍和触碰产品、现金与资产支付、结算时机、观察方式及历史状态的既有支持组合。
- [x] 保留触碰即付、到期支付和已支付历史等事件语义，不把未知历史默认为无事件。
- [x] 交付现有解析价格、可用 Greeks、敏感度和反求；已固定现金流的参数不可识别状态按契约拒绝。
- [x] 通过现有二元障碍、单触碰和结算回归及独立参考，验证观察边界、严格既往历史和替换失败状态。
- [x] 通过 Rust 与 Python 公共 API 验收本票能力，等价领域场景使用同一核心语义与默认值；适配层只处理协议、转换、异常和所有权，导出、类型声明与用法文档同步。
- [x] 迁移本票适用的现有契约与数值回归，覆盖合法和非法输入、验证时机、稳定错误类别及失败状态；Python 表示错误保留原生异常并拒绝意外有损转换。
- [x] 本票与已完成切片在隔离候选环境中通过测试，旧实现继续用于迁移对照；不提前删除旧实现，不新增性能回归门槛或性能报告要求。
