# 05: 数字期权解析定价

**What to build:** 用户可以构造现金或无、资产或无数字期权，并通过 Rust 与 Python 获取现有解析价格及支持的分析结果。

**Blocked by:** 04: Greeks、数值敏感度与隐含波动率。

**Status:** ready-for-agent

- [ ] 迁移两类数字期权及现有方向、支付与结算语义，保留构造和替换验证、拥有值及默认值。
- [ ] 交付既有解析价格、Greeks、数值敏感度和可适用的隐含波动率能力；不扩展不受支持的产品与操作组合。
- [ ] 覆盖价内、价外、平值、到期、估值边界和既有溢出、折现下溢回归；领域输入和结果错误保持既有类别。
- [ ] 迁移相关数字期权公开 API 测试，通过现有独立定价及 Greeks 参考验证结果。
- [ ] 通过 Rust 与 Python 公共 API 验收本票能力，等价领域场景使用同一核心语义与默认值；适配层只处理协议、转换、异常和所有权，导出、类型声明与用法文档同步。
- [ ] 迁移本票适用的现有契约与数值回归，覆盖合法和非法输入、验证时机、稳定错误类别及失败状态；Python 表示错误保留原生异常并拒绝意外有损转换。
- [ ] 本票与已完成切片在隔离候选环境中通过测试，旧实现继续用于迁移对照；不提前删除旧实现，不新增性能回归门槛或性能报告要求。
