# 28: 基础雪球与数值积分

**What to build:** 用户可以构造基础雪球及其观察记录和历史状态，并通过积分引擎在两种语言中定价。

**Blocked by:** 03: 交易日历、观察日程与生成工具；08: 香草与数字期权数值积分。

**Status:** ready-for-agent

- [ ] 贯通基础雪球及共用结构化条款、观察记录、敲入敲出状态、到期支付和已有基础构造方式。
- [ ] 未知历史与明确无事件分开，观察记录与历史替换先通过核心验证；非法或缺失状态不提交。
- [ ] 使用现有结构化积分方法交付基础雪球价格、Greeks、敏感度与隐含波动率支持，保留交易日和事件顺序。
- [ ] 以现有基础雪球 API、结构化终端支付组合、积分回归及收敛检查验证；为后续凤凰和雪球变体保留已验证的共用领域行为。
- [ ] 通过 Rust 与 Python 公共 API 验收本票能力，等价领域场景使用同一核心语义与默认值；适配层只处理协议、转换、异常和所有权，导出、类型声明与用法文档同步。
- [ ] 迁移本票适用的现有契约与数值回归，覆盖合法和非法输入、验证时机、稳定错误类别及失败状态；Python 表示错误保留原生异常并拒绝意外有损转换。
- [ ] 本票与已完成切片在隔离候选环境中通过测试，旧实现继续用于迁移对照；不提前删除旧实现，不新增性能回归门槛或性能报告要求。
