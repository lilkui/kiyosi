# 16: 单障碍解析定价与事件历史

**What to build:** 用户可以构造具有现有观察方式、返还和历史状态的单障碍期权，并在受支持范围内进行解析定价。

**Blocked by:** 03: 交易日历、观察日程与生成工具；04: Greeks、数值敏感度与隐含波动率。

**Status:** completed

- [x] 迁移单障碍条款、观察日程、触碰状态与返还时机，保留包括边界触碰在内的事件顺序和核心验证。
- [x] 未知历史与明确未触碰分开表示；历史相对估值时点的要求和替换失败状态得到公共 API 测试。
- [x] 交付现有解析支持组合、Greeks、敏感度及反求能力；可以表示但不受支持的配置返回核心领域错误，不静默回退。
- [x] 覆盖连续和日程相关的现有适用边界、已触碰与已结算状态、到期及返还支付，并与既有独立参考对照。
- [x] 通过 Rust 与 Python 公共 API 验收本票能力，等价领域场景使用同一核心语义与默认值；适配层只处理协议、转换、异常和所有权，导出、类型声明与用法文档同步。
- [x] 迁移本票适用的现有契约与数值回归，覆盖合法和非法输入、验证时机、稳定错误类别及失败状态；Python 表示错误保留原生异常并拒绝意外有损转换。
- [x] 本票与已完成切片在隔离候选环境中通过测试，旧实现继续用于迁移对照；不提前删除旧实现，不新增性能回归门槛或性能报告要求。
