# 23: 双障碍有限差分

**What to build:** 用户可以用 FD 引擎定价现有双障碍产品，正确处理上下边界和观察事件。

**Blocked by:** 18: 双障碍解析定价；21: 单障碍有限差分。

**Status:** ready-for-agent

- [ ] 复用单障碍 FD 行为和双障碍领域条款，保留既有方案、观察、返还与历史支持组合。
- [ ] 在共同观察日程下处理上下两界的触碰与估值、到期事件，输入和配置验证保持一致。
- [ ] 交付现有价格、Greeks、敏感度与反求，保留共享 FD 设置及结果可用性语义。
