# 36: 累购蒙特卡洛

**What to build:** 用户可以用交易日 CPU 模拟定价累购，并获得现有统计结果、共享样本分析及隐含波动率能力。

**Blocked by:** 11: 欧式 Sobol 与对偶变量；34: 累购与数值积分。

**Status:** ready-for-agent

- [ ] 沿用累购交易日步进、累计支付、历史和终止规则，事件顺序与现有领域语义一致。
- [ ] 接入现有伪随机、Sobol、对偶与线程配置，保留维度、路径数、seed 和适用统计结果。
- [ ] 交付现有共享样本 Greeks、数值敏感度与隐含波动率行为，覆盖缺失历史、固定支付和不可识别状态。
- [ ] 迁移累购 MC、对偶及线程一致性案例，通过积分或 FD 参考和统计检查验证，不要求 C++ 随机流逐位一致。
- [ ] 通过 Rust 与 Python 公共 API 验收本票能力，等价领域场景使用同一核心语义与默认值；适配层只处理协议、转换、异常和所有权，导出、类型声明与用法文档同步。
- [ ] 迁移本票适用的现有契约与数值回归，覆盖合法和非法输入、验证时机、稳定错误类别及失败状态；Python 表示错误保留原生异常并拒绝意外有损转换。
- [ ] 本票与已完成切片在隔离候选环境中通过测试，旧实现继续用于迁移对照；不提前删除旧实现，不新增性能回归门槛或性能报告要求。
