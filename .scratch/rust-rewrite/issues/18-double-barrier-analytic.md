# 18: 双障碍解析定价

**What to build:** 用户可以构造双障碍产品并使用现有连续观察解析引擎，保留上下边界、历史与返还语义。

**Blocked by:** 16: 单障碍解析定价与事件历史。

**Status:** ready-for-agent

- [ ] 迁移双障碍条款与方向、上下边界顺序、共同观察日程、触碰历史和返还配置，所有领域验证由核心执行。
- [ ] 现有连续观察解析范围、价格与适用分析能力保持一致，不扩大离散观察或返还方式的解析支持。
- [ ] 覆盖在任一边界触碰、已触碰、到期和上下界接近等既有数值边界，保留稳定计算和错误类别。
- [ ] 迁移现有双障碍解析回归，结合独立参考及适用的价格关系验证；两种语言分别测试历史替换和非法组合。
- [ ] 通过 Rust 与 Python 公共 API 验收本票能力，等价领域场景使用同一核心语义与默认值；适配层只处理协议、转换、异常和所有权，导出、类型声明与用法文档同步。
- [ ] 迁移本票适用的现有契约与数值回归，覆盖合法和非法输入、验证时机、稳定错误类别及失败状态；Python 表示错误保留原生异常并拒绝意外有损转换。
- [ ] 本票与已完成切片在隔离候选环境中通过测试，旧实现继续用于迁移对照；不提前删除旧实现，不新增性能回归门槛或性能报告要求。
