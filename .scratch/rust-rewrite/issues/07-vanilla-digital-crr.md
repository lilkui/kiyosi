# 07: 香草与数字期权 CRR

**What to build:** 用户可以通过两种公开 API 对现有香草与数字期权支持组合使用 CRR 二叉树，并请求适用的分析结果。

**Blocked by:** 05: 数字期权解析定价；06: 美式近似定价。

**Status:** ready-for-agent

- [ ] 覆盖现有欧式、美式香草及现金或无、资产或无数字期权的 CRR 支持矩阵，不扩大类型或领域支持范围。
- [ ] 步数与相关配置默认值来自核心，保留参数边界、风险中性概率及数值结果有效性的验证与错误。
- [ ] 保留美式提前行权、数字支付与结算边界，以及各组合既有 Greeks、数值敏感度和隐含波动率能力。
- [ ] 在公共 API 验证网格细化、定价与 Greeks 回归，并与现有适用的独立参考或解析极限比较。
- [ ] 通过 Rust 与 Python 公共 API 验收本票能力，等价领域场景使用同一核心语义与默认值；适配层只处理协议、转换、异常和所有权，导出、类型声明与用法文档同步。
- [ ] 迁移本票适用的现有契约与数值回归，覆盖合法和非法输入、验证时机、稳定错误类别及失败状态；Python 表示错误保留原生异常并拒绝意外有损转换。
- [ ] 本票与已完成切片在隔离候选环境中通过测试，旧实现继续用于迁移对照；不提前删除旧实现，不新增性能回归门槛或性能报告要求。
