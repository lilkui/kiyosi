# 27: 区间累计解析定价

**What to build:** 用户可以依据交易日观察和既往命中次数，对现有区间累计产品计算解析价格及适用分析结果。

**Blocked by:** 03: 交易日历、观察日程与生成工具；04: Greeks、数值敏感度与隐含波动率。

**Status:** ready-for-agent

- [ ] 迁移区间累计条款、观察交易日、区间边界、年化与支付规则，不增加本金支付或提前终止功能。
- [ ] 已实现命中历史、缺失历史和估值时点一致性在既有时机验证；替换返回拥有的新值并保留失败状态保证。
- [ ] 使用既有边际概率解析方法，交付价格与现有 Greeks、敏感度或反求支持，不增加新的支持组合。
- [ ] 通过现有区间累计公开 API、终端支付和日期边界案例验证，并与独立可构造的支付参考核对。
- [ ] 通过 Rust 与 Python 公共 API 验收本票能力，等价领域场景使用同一核心语义与默认值；适配层只处理协议、转换、异常和所有权，导出、类型声明与用法文档同步。
- [ ] 迁移本票适用的现有契约与数值回归，覆盖合法和非法输入、验证时机、稳定错误类别及失败状态；Python 表示错误保留原生异常并拒绝意外有损转换。
- [ ] 本票与已完成切片在隔离候选环境中通过测试，旧实现继续用于迁移对照；不提前删除旧实现，不新增性能回归门槛或性能报告要求。
