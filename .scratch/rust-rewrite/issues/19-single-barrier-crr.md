# 19: 单障碍 CRR

**What to build:** 用户可以用现有 CRR 方法定价单障碍期权，并获得适用的分析结果。

**Blocked by:** 07: 香草与数字期权 CRR；16: 单障碍解析定价与事件历史。

**Status:** ready-for-agent

- [ ] 复用已验证的 CRR 能力与障碍领域条款，覆盖现有产品、观察和返还支持组合。
- [ ] 按现有规则处理原观察日期、到期、触碰与历史状态，不通过自动改动日程改变事件语义。
- [ ] 交付价格及既有 Greeks、敏感度和反求，配置默认值、验证时机和不受支持组合错误一致。
- [ ] 迁移单障碍二叉树收敛与定价回归，通过适用解析或独立参考验证，并保持此前切片测试通过。
- [ ] 通过 Rust 与 Python 公共 API 验收本票能力，等价领域场景使用同一核心语义与默认值；适配层只处理协议、转换、异常和所有权，导出、类型声明与用法文档同步。
- [ ] 迁移本票适用的现有契约与数值回归，覆盖合法和非法输入、验证时机、稳定错误类别及失败状态；Python 表示错误保留原生异常并拒绝意外有损转换。
- [ ] 本票与已完成切片在隔离候选环境中通过测试，旧实现继续用于迁移对照；不提前删除旧实现，不新增性能回归门槛或性能报告要求。
