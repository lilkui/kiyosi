# 01: 欧式解析定价贯通

**What to build:** Rust 和 Python 用户可以在隔离安装的 Rust 候选包中构造欧式期权及 BSM 市场上下文并获得解析价格，同时保留旧实现用于迁移对照。

**Blocked by:** None (can start immediately)。

**Status:** ready-for-agent

- [ ] 建立独立 Rust 核心与 PyO3 绑定 crate，由 maturin 构建候选 Python 包；核心能在无 Python 和绑定框架参与时构建、测试并由独立 Rust 消费方调用。
- [ ] 欧式看涨、看跌的有效输入、估值时点和到期边界沿用现有领域语义；通过公开 API 得到价格，并与现有解析案例及独立参考对照。
- [ ] 引入本切片所需的核心错误类别、拥有值、严格数值与日期转换和从核心派生的 Python 默认值；文档区分领域拒绝、表示错误、资源耗尽及内部失败。
- [ ] 候选包具有一致的版本、导出和类型声明；建立最小构建与公共 API 测试检查，记录同步调用和线程安全默认契约。
- [ ] 旧版与候选版在独立环境或进程中验证，旧实现与既有交付保持可用；不增加用户可见的双实现切换开关。
