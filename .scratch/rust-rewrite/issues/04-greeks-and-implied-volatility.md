# 04: Greeks、数值敏感度与隐含波动率

**What to build:** 用户可以对欧式期权请求现有 Greeks 和数值敏感度，并从价格反求隐含波动率，获得可辨别的成功结果或失败类别。

**Blocked by:** 02: 期限结构与市场替换。

**Status:** ready-for-agent

- [ ] 迁移既有 Greek 请求、解析与数值结果、差分设置和结果可用性规则；覆盖混合请求、默认值、估值与到期边界。
- [ ] 公开隐含波动率接口保留区间、收敛控制、价格校验、无括区间、不收敛、非有限求解和参数不可识别时的错误语义。
- [ ] 在 Rust 核心提供供后续引擎复用的既有分析与求解行为，Python 不复制领域规则或默认值。
- [ ] 通过公开 API 的 Greeks 对照、差分步长稳定性、波动率恢复和实时 QuantLib 案例验证，不以误差预算放宽掩盖差异。
- [ ] 通过 Rust 与 Python 公共 API 验收本票能力，等价领域场景使用同一核心语义与默认值；适配层只处理协议、转换、异常和所有权，导出、类型声明与用法文档同步。
- [ ] 迁移本票适用的现有契约与数值回归，覆盖合法和非法输入、验证时机、稳定错误类别及失败状态；Python 表示错误保留原生异常并拒绝意外有损转换。
- [ ] 本票与已完成切片在隔离候选环境中通过测试，旧实现继续用于迁移对照；不提前删除旧实现，不新增性能回归门槛或性能报告要求。
