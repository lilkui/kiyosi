# 22: 二元障碍与单边触碰有限差分

**What to build:** 用户可以通过 FD 引擎定价现有二元障碍和单触碰、不触碰组合，并按支付与结算约定获得结果。

**Blocked by:** 09: 香草与数字期权有限差分；17: 二元障碍与单边触碰解析。

**Status:** completed

- [x] 迁移现有二元障碍与触碰系列 FD 支持矩阵，保留现金或资产支付、结算时机和边界条件。
- [x] 观察、既往历史、已支付与到期状态按核心规则处理，未知与未发生事件保持可区分。
- [x] 交付现有价格、Greeks、敏感度及反求能力；固定现金流与无效组合的拒绝类别保持一致。
- [x] 迁移对应 FD、结算、折现与数值回归，以适用解析参考和网格收敛检查验证两种 API。
- [x] 通过 Rust 与 Python 公共 API 验收本票能力，等价领域场景使用同一核心语义与默认值；适配层只处理协议、转换、异常和所有权，导出、类型声明与用法文档同步。
- [x] 迁移本票适用的现有契约与数值回归，覆盖合法和非法输入、验证时机、稳定错误类别及失败状态；Python 表示错误保留原生异常并拒绝意外有损转换。
- [x] 本票与已完成切片在隔离候选环境中通过测试，旧实现继续用于迁移对照；不提前删除旧实现，不新增性能回归门槛或性能报告要求。
