# 06: 美式近似定价

**What to build:** 用户可以在两种语言中构造美式香草期权并使用现有 Bjerksund–Stensland 近似进行定价和支持的分析。

**Blocked by:** 04: Greeks、数值敏感度与隐含波动率。

**Status:** ready-for-agent

- [ ] 保留美式条款、行权范围、构造验证与替换行为，Bjerksund–Stensland 使用现有公式和适用范围。
- [ ] 交付既有价格、支持的 Greeks、数值敏感度及隐含波动率调用，不引入新的美式近似或静默替代算法。
- [ ] 覆盖提前行权、欧式极限、到期与非法配置边界，验证结构化错误类别与失败状态。
- [ ] 采用现有美式近似回归和独立参考案例验证；说明近似与精确参考之间适用的既有精度标准。
- [ ] 通过 Rust 与 Python 公共 API 验收本票能力，等价领域场景使用同一核心语义与默认值；适配层只处理协议、转换、异常和所有权，导出、类型声明与用法文档同步。
- [ ] 迁移本票适用的现有契约与数值回归，覆盖合法和非法输入、验证时机、稳定错误类别及失败状态；Python 表示错误保留原生异常并拒绝意外有损转换。
- [ ] 本票与已完成切片在隔离候选环境中通过测试，旧实现继续用于迁移对照；不提前删除旧实现，不新增性能回归门槛或性能报告要求。
