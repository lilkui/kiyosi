# 26: 双障碍蒙特卡洛

**What to build:** 用户可以使用现有 CPU 蒙特卡洛能力定价双障碍期权，保留共同观察和历史事件语义。

**Blocked by:** 18: 双障碍解析定价；25: 单障碍蒙特卡洛。

**Status:** completed

- [x] 沿用现有双障碍模拟及条件存活处理，覆盖现有连续与日程观察、返还和历史支持范围。
- [x] 复用已交付的 CPU 采样与线程契约，支持既有伪随机、Sobol 和对偶组合，不改变合同观察日程。
- [x] 保留价格、适用统计结果、共享样本 Greeks 和反求语义，以及双边界有效性与固定现金流的领域拒绝。
- [x] 迁移双障碍 MC 回归，在适用范围内与解析、FD 或独立参考作统计与收敛比较，不要求新旧随机流相同。
- [x] 通过 Rust 与 Python 公共 API 验收本票能力，等价领域场景使用同一核心语义与默认值；适配层只处理协议、转换、异常和所有权，导出、类型声明与用法文档同步。
- [x] 迁移本票适用的现有契约与数值回归，覆盖合法和非法输入、验证时机、稳定错误类别及失败状态；Python 表示错误保留原生异常并拒绝意外有损转换。
- [x] 本票与已完成切片在隔离候选环境中通过测试，旧实现继续用于迁移对照；不提前删除旧实现，不新增性能回归门槛或性能报告要求。
