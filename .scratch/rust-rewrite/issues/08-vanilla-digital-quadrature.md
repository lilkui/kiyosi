# 08: 香草与数字期权数值积分

**What to build:** 用户可以在 Rust 与 Python 中使用现有数值积分引擎定价受支持的香草和数字期权。

**Blocked by:** 05: 数字期权解析定价。

**Status:** ready-for-agent

- [ ] 迁移现有积分方法与香草、数字支持组合，保留积分配置、截断与精度参数的默认值和验证。
- [ ] 交付现有价格、适用的 Greeks、数值敏感度和隐含波动率调用，不为未支持组合增加隐式回退。
- [ ] 覆盖到期、极端有效市场输入、数字支付和折现边界，并验证非法设置和无效数值结果的错误类别。
- [ ] 迁移现有积分回归与收敛案例，通过解析或独立参考验证，供后续路径依赖积分产品复用已验证的行为。
- [ ] 通过 Rust 与 Python 公共 API 验收本票能力，等价领域场景使用同一核心语义与默认值；适配层只处理协议、转换、异常和所有权，导出、类型声明与用法文档同步。
- [ ] 迁移本票适用的现有契约与数值回归，覆盖合法和非法输入、验证时机、稳定错误类别及失败状态；Python 表示错误保留原生异常并拒绝意外有损转换。
- [ ] 本票与已完成切片在隔离候选环境中通过测试，旧实现继续用于迁移对照；不提前删除旧实现，不新增性能回归门槛或性能报告要求。
