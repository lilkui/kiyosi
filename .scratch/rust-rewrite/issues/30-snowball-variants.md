# 30: 雪球产品变体

**What to build:** 用户可以使用现有二元、三元雪球及命名预设，展开相同领域条款并通过积分引擎定价。

**Blocked by:** 28: 基础雪球与数值积分。

**Status:** ready-for-agent

- [ ] 核对并迁移所有既有二元、三元雪球和命名预设，逐项覆盖现有敲入观察、票息与敲出阶梯、行权和本金配置。
- [ ] 预设只在核心中展开并复用权威领域构造与验证，Python 不重复拼装规则或定义默认值。
- [ ] 各变体通过现有积分引擎获得价格及已有分析操作，历史、观察和替换失败保证保持一致。
- [ ] 逐项比较预设与等价显式条款的结果，并迁移既有支付、参数与数值回归；不得只以预设名称存在视为完成。
- [ ] 通过 Rust 与 Python 公共 API 验收本票能力，等价领域场景使用同一核心语义与默认值；适配层只处理协议、转换、异常和所有权，导出、类型声明与用法文档同步。
- [ ] 迁移本票适用的现有契约与数值回归，覆盖合法和非法输入、验证时机、稳定错误类别及失败状态；Python 表示错误保留原生异常并拒绝意外有损转换。
- [ ] 本票与已完成切片在隔离候选环境中通过测试，旧实现继续用于迁移对照；不提前删除旧实现，不新增性能回归门槛或性能报告要求。
