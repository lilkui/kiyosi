# 13: 数字期权蒙特卡洛

**What to build:** 用户可以对现金或无和资产或无数字期权使用现有 CPU 蒙特卡洛支持组合。

**Blocked by:** 05: 数字期权解析定价；11: 欧式 Sobol 与对偶变量。

**Status:** ready-for-agent

- [ ] 保留数字支付、结算和终端采样语义，支持现有伪随机、Sobol、对偶变量与线程配置。
- [ ] 交付适用的价格、统计结果、Greeks、数值敏感度和反求能力，不增加既有支持矩阵之外的操作。
- [ ] 覆盖不连续支付、到期、平值以及既有大额支付、折现和溢出回归，结构化错误保持一致。
- [ ] 通过数字解析参考、现有统计案例、固定 seed 及跨线程数检查验证两种语言的等价场景。
- [ ] 通过 Rust 与 Python 公共 API 验收本票能力，等价领域场景使用同一核心语义与默认值；适配层只处理协议、转换、异常和所有权，导出、类型声明与用法文档同步。
- [ ] 迁移本票适用的现有契约与数值回归，覆盖合法和非法输入、验证时机、稳定错误类别及失败状态；Python 表示错误保留原生异常并拒绝意外有损转换。
- [ ] 本票与已完成切片在隔离候选环境中通过测试，旧实现继续用于迁移对照；不提前删除旧实现，不新增性能回归门槛或性能报告要求。
