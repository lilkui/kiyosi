# 10: 欧式蒙特卡洛与 CPU 并发

**What to build:** 用户可以进行欧式 CPU 伪随机蒙特卡洛定价，获取适用的统计与分析结果，并按调用控制线程数。

**Blocked by:** 04: Greeks、数值敏感度与隐含波动率。

**Status:** ready-for-agent

- [ ] 保留欧式精确终端分布采样、路径数、步数验证、可选 seed 和相关核心默认值，不引入中间步进改变算法。
- [ ] 交付适用的标准误差、置信区间、共享样本 Greeks 和隐含波动率行为；一次分析或求解按现有规则共享 seed。
- [ ] 线程数的自动、串行与指定上限按调用生效，不修改进程全局并发设置；同一构建内固定 seed 的结果保留既有线程数无关性。
- [ ] Python 核心计算按线程安全契约释放 GIL，释放期间不触碰 Python 对象；同步、信号和资源失败语义有文档。
- [ ] 通过解析参考、统计正确性和公开 API 并发案例验收，验证路径与线程边界，不比较线程加速比。
- [ ] 通过 Rust 与 Python 公共 API 验收本票能力，等价领域场景使用同一核心语义与默认值；适配层只处理协议、转换、异常和所有权，导出、类型声明与用法文档同步。
- [ ] 迁移本票适用的现有契约与数值回归，覆盖合法和非法输入、验证时机、稳定错误类别及失败状态；Python 表示错误保留原生异常并拒绝意外有损转换。
- [ ] 本票与已完成切片在隔离候选环境中通过测试，旧实现继续用于迁移对照；不提前删除旧实现，不新增性能回归门槛或性能报告要求。
