# 02: 期限结构与市场替换

**What to build:** 用户可以通过两种语言的市场 API 配置现有利率与股息率期限结构，并在欧式定价中使用或替换这些市场值。

**Blocked by:** 01: 欧式解析定价贯通。

**Status:** ready-for-agent

- [ ] 保留现有平坦及非平坦曲线的构造、查询、折现、时间与边界语义；两种语言对等价曲线和上下文得到一致的领域行为。
- [ ] 欧式解析定价实际消费配置的期限结构，并通过现有曲线定价案例及可适用的独立参考验证。
- [ ] 市场参数和上下文的替换先由核心验证，成功返回拥有的新值，失败保持原对象及输入有效；只读属性和生命周期行为得到测试。
- [ ] 覆盖无效曲线节点、时间范围、非有限领域输入及日期时间表示边界，验证原生转换异常与核心错误类别的区别。
- [ ] 通过 Rust 与 Python 公共 API 验收本票能力，等价领域场景使用同一核心语义与默认值；适配层只处理协议、转换、异常和所有权，导出、类型声明与用法文档同步。
- [ ] 迁移本票适用的现有契约与数值回归，覆盖合法和非法输入、验证时机、稳定错误类别及失败状态；Python 表示错误保留原生异常并拒绝意外有损转换。
- [ ] 本票与已完成切片在隔离候选环境中通过测试，旧实现继续用于迁移对照；不提前删除旧实现，不新增性能回归门槛或性能报告要求。
