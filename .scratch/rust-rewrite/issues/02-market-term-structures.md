# 02: 期限结构与市场替换

**What to build:** 用户可以通过两种语言的市场 API 配置现有利率与股息率期限结构，并在欧式定价中使用或替换这些市场值。

**Blocked by:** 01: 欧式解析定价贯通。

**Status:** completed

- [x] 保留现有平坦及非平坦曲线的构造、查询、折现、时间与边界语义；两种语言对等价曲线和上下文得到一致的领域行为。
- [x] 欧式解析定价实际消费配置的期限结构，并通过现有曲线定价案例及可适用的独立参考验证。

- [x] 本票与已完成切片在隔离候选环境中通过测试，旧实现继续用于迁移对照；不提前删除旧实现，不新增性能回归门槛或性能报告要求。

- Rust 核心提供平坦与节点期限结构、区间折现/对数折现、右侧远期、平行移动和拥有值替换；BSM 模型支持独立配置两条曲线，欧式解析定价消费估值至到期的积分利率。
