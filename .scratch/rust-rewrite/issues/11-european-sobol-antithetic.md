# 11: 欧式 Sobol 与对偶变量

**What to build:** 用户可以在欧式蒙特卡洛中选择现有 Sobol 或伪随机采样及对偶变量，并获得符合采样方法的结果。

**Blocked by:** 10: 欧式蒙特卡洛与 CPU 并发。

**Status:** ready-for-agent

- [ ] 迁移现有 Sobol 扰乱、数字位移、seed 和维度规则，方向数数据及其第三方许可完整保留。
- [ ] 保留 Sobol 路径数约束及不报告标准误差和置信区间的规则，不把准蒙特卡洛结果伪装成伪随机统计量。
- [ ] 对偶变量支持范围与路径计数保持现状，覆盖允许的奇数路径、不成对路径及与 Sobol 组合的边界。
- [ ] 所有现有欧式采样组合通过价格、分析操作、可复现性及跨线程数案例；允许随机流不同于 C++，不要求逐位跨实现比较。
- [ ] 从混合计时工具中保留统计与精度断言，不把采样速度优势或耗时比较作为通过条件。
- [ ] 通过 Rust 与 Python 公共 API 验收本票能力，等价领域场景使用同一核心语义与默认值；适配层只处理协议、转换、异常和所有权，导出、类型声明与用法文档同步。
- [ ] 迁移本票适用的现有契约与数值回归，覆盖合法和非法输入、验证时机、稳定错误类别及失败状态；Python 表示错误保留原生异常并拒绝意外有损转换。
- [ ] 本票与已完成切片在隔离候选环境中通过测试，旧实现继续用于迁移对照；不提前删除旧实现，不新增性能回归门槛或性能报告要求。
