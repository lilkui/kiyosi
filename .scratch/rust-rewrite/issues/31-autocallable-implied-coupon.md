# 31: 结构化产品隐含票息

**What to build:** 用户可以通过积分引擎对现有雪球系列和凤凰反求票息，显式选择适用的报价约定并辨别失败原因。

**Blocked by:** 29: 凤凰与数值积分；30: 雪球产品变体。

**Status:** completed

- [x] 迁移雪球系列报价约定及凤凰无歧义票息反求，参数默认值、端点、收敛和验证规则来自核心。
- [x] 保持既有票息替换语义、到期票息联动约定和积分引擎的票息价格关系；求解不修改原产品或上下文。
- [x] 无票息暴露、无括区间、非有限试价与不收敛等状态使用稳定类别，验证时机与既有契约一致。
- [x] 在两种 API 通过价格到票息恢复、残差和不可识别性案例验证所有适用产品，为后续 FD、MC 票息求解复用该公开契约。
- [x] 通过 Rust 与 Python 公共 API 验收本票能力，等价领域场景使用同一核心语义与默认值；适配层只处理协议、转换、异常和所有权，导出、类型声明与用法文档同步。
- [x] 迁移本票适用的现有契约与数值回归，覆盖合法和非法输入、验证时机、稳定错误类别及失败状态；Python 表示错误保留原生异常并拒绝意外有损转换。
- [x] 本票与已完成切片在隔离候选环境中通过测试，旧实现继续用于迁移对照；不提前删除旧实现，不新增性能回归门槛或性能报告要求。
