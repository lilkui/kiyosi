# 15: 亚式蒙特卡洛

**What to build:** 用户可以对现有几何与算术平均亚式产品进行 CPU 蒙特卡洛定价及支持的分析。

**Blocked by:** 11: 欧式 Sobol 与对偶变量；14: 亚式解析与算术平均近似。

**Status:** ready-for-agent

- [ ] 保留几何平均和单次固定的精确分布采样，以及算术平均既有时间积分与首区间处理；前向起始单独处理。
- [ ] 支持已有伪随机、Sobol、对偶变量和线程设置，保持维度限制、路径计数、seed 和统计结果规则。
- [ ] 保留历史平均、剩余平均窗口和共享样本 Greeks、反求的语义，不改变现有默认差分配置。
- [ ] 通过几何解析参考、算术平均统计与收敛案例、亚式线程正确性和历史边界回归验证，不添加耗时门槛。
- [ ] 通过 Rust 与 Python 公共 API 验收本票能力，等价领域场景使用同一核心语义与默认值；适配层只处理协议、转换、异常和所有权，导出、类型声明与用法文档同步。
- [ ] 迁移本票适用的现有契约与数值回归，覆盖合法和非法输入、验证时机、稳定错误类别及失败状态；Python 表示错误保留原生异常并拒绝意外有损转换。
- [ ] 本票与已完成切片在隔离候选环境中通过测试，旧实现继续用于迁移对照；不提前删除旧实现，不新增性能回归门槛或性能报告要求。
