**What to build:** 用户可以对现有几何与算术平均亚式产品进行 CPU 蒙特卡洛定价及支持的分析。

**Blocked by:** 11: 欧式 Sobol 与对偶变量；14: 亚式解析与算术平均近似。

**Status:** completed

- [x] 保留几何平均和单次固定的精确分布采样，以及算术平均既有时间积分与首区间处理；前向起始单独处理。
- [x] 支持已有伪随机、Sobol、对偶变量和线程设置，保持维度限制、路径计数、seed 和统计结果规则。
- [x] 保留历史平均、剩余平均窗口和共享样本 Greeks、反求的语义，不改变现有默认差分配置。
