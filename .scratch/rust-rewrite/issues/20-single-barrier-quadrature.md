# 20: 单障碍数值积分

**What to build:** 用户可以通过数值积分对受支持的单障碍期权定价，保留现有观察事件与返还行为。

**Blocked by:** 08: 香草与数字期权数值积分；16: 单障碍解析定价与事件历史。

**Status:** ready-for-agent

- [ ] 复用已验证的积分方法，迁移单障碍现有观察方式、返还和历史支持组合，不改变积分算法。
- [ ] 保留观察日期、估值日和到期日的事件处理，验证缺失历史、已触碰与已结算状态。
- [ ] 交付现有价格、Greeks、敏感度和反求，配置与无效结果错误维持领域契约。
- [ ] 迁移相关积分回归与收敛案例，以适用解析和独立参考核验精度，不以跨实现浮点逐位一致作为要求。
- [ ] 通过 Rust 与 Python 公共 API 验收本票能力，等价领域场景使用同一核心语义与默认值；适配层只处理协议、转换、异常和所有权，导出、类型声明与用法文档同步。
- [ ] 迁移本票适用的现有契约与数值回归，覆盖合法和非法输入、验证时机、稳定错误类别及失败状态；Python 表示错误保留原生异常并拒绝意外有损转换。
- [ ] 本票与已完成切片在隔离候选环境中通过测试，旧实现继续用于迁移对照；不提前删除旧实现，不新增性能回归门槛或性能报告要求。
