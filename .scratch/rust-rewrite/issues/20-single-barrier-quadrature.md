**Blocked by:** 08: 香草与数字期权数值积分；16: 单障碍解析定价与事件历史。

**Status:** completed

## Comments

2026-10-28：本票已完成。

- Rust 与 Python 候选公开 `QuadratureBarrierEngine`；Rust `QuadratureSettings` 默认 512 个资产步、8 个标准差，最少四步、有限正积分范围。Python 默认值来自核心，整数预算采用 `numbers.Integral` 与 index 协议，拒绝 bool、浮点缩窄与越界转换；绑定仅处理表示、异常、拥有值与 GIL 释放。
- 沿用连续观察的分段 Simpson、Brownian bridge 存活概率及首次触碰返还积分；日程观察沿用三次插值、条件 Gaussian 矩、精确分段终值与尾部边界、补偿求和及对数缩放。仅复用完全相同的平移单元几何与转移时长，不改变积分算法，不新增依赖。
- 复用核心原午夜观察日、交易日验证、严格既往历史、当前触碰与已结算语义；支持提前结束观察窗与到期观察。已触碰的 at-hit 返还不重复支付，原观察日期不移动。期限结构节点仍返回 `UnsupportedOperation`，不可表示网格、转移与结果返回 `InvalidResult`。
