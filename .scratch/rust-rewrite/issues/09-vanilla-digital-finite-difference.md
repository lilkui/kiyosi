# 09: 香草与数字期权有限差分

**What to build:** 用户可以用现有有限差分方案定价支持的香草、数字期权，并处理美式行权及相应分析请求。

**Blocked by:** 05: 数字期权解析定价；06: 美式近似定价。

**Status:** ready-for-agent

- [ ] 迁移现有 FD 方案、网格、阻尼及相关配置规则，支持矩阵与核心默认值保持一致。
- [ ] 覆盖欧式终端支付、美式提前行权、数字不连续支付及其既有边界处理，不切换数值方法。
- [ ] 交付既有 Greeks、数值敏感度和隐含波动率能力；验证混合 Greeks、步长、网格及配置错误。
- [ ] 迁移现有 FD 网格细化、Rannacher、插值、折现和 Greeks 数值回归，通过公共 API 与独立参考验证。
- [ ] 通过 Rust 与 Python 公共 API 验收本票能力，等价领域场景使用同一核心语义与默认值；适配层只处理协议、转换、异常和所有权，导出、类型声明与用法文档同步。
- [ ] 迁移本票适用的现有契约与数值回归，覆盖合法和非法输入、验证时机、稳定错误类别及失败状态；Python 表示错误保留原生异常并拒绝意外有损转换。
- [ ] 本票与已完成切片在隔离候选环境中通过测试，旧实现继续用于迁移对照；不提前删除旧实现，不新增性能回归门槛或性能报告要求。
