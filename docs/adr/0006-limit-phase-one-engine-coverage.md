# Limit Phase 1 engine coverage

Phase 1 will provide one reference engine per core family plus numerical cross-checks: analytic European, digital, and barrier pricing; binomial American pricing; and finite-difference European and American pricing. Integral, Asian, structured-product, Monte Carlo, and CUDA engines remain later work. The library starts at version `0.1.0` with semantic versioning, no stable ABI promise before `1.0`, and no performance acceptance requirement.
