# CPU 功能范围与正确性契约

Rust 版本完整覆盖现有 CPU 产品与引擎的支持组合，以及 Greeks、隐含参数求解、期限结构、交易日历、观察日程和历史记录；不新增产品或算法。为控制实现和分发成本，执行后端仅支持 CPU，不包含 CUDA 后端或其桥接层。

领域行为须保持一致，包括默认值、有效输入范围、事件边界、错误类别、验证时机、失败状态保证和线程安全契约。数值结果按适用的精度与统计标准验收，允许浮点末位和随机序列变化，不要求同一 seed 的结果与 C++ 实现逐位一致；正确性依据现有测试、独立 QuantLib 对照和收敛检查，现有实现与正确性要求冲突时须单独确认。

本次验收不设置性能收益目标或性能回归门槛，不要求建立性能对照基线；精度与统计正确性检查仍为必需项。
