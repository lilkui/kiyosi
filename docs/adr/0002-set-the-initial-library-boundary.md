# Set a focused initial library boundary

The initial library will be delivered in stages: first the single-underlying BSM domain, time and schedule rules, numerics, and deterministic engines for vanilla, digital, and barrier instruments; Asians, structured products, Monte Carlo, and CUDA follow later. The first release targets Windows and Linux with C++23 and CMake, keeps the core standard-library-only, and treats prices, Greeks, solver results, and deterministic edge cases as parity obligations.
