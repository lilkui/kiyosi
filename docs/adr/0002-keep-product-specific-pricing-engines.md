# 在定价引擎类型上表达产品覆盖

引擎类型名表达算法和适用的合约族，调用者切换解析、积分、二叉树、有限差分或蒙特卡洛时沿用相同的选择方式。有限差分的多种合约族共用网格设置，仍各自提供引擎类型。支持同一操作的引擎共用方法名。按行权价批量定价使用 `price_strikes`，模板类型表达合约及行权方式，具体引擎决定支持范围和可复用的计算。

Rust 的通用定价通过 `PricingEngine` 调用，合约类型决定使用的实现。调用者导入一次 trait 即可切换引擎，具体引擎和泛型调用共用同一实现。

采样统计也通过 `PricingEngine` 调用。无统计估计量的引擎与合约组合（包括美式香草蒙特卡洛）返回 `UnsupportedOperation`。
